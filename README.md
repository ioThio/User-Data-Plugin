# User Data Plugin

A WordPress plugin experiment that displays registered users' profile information through the `[list_users]` shortcode.

## What it does

The original plugin displays usernames, email addresses, group names, websites, and biographical information on the front end of a WordPress site.

## Project status

This is a legacy project from 2022, retained for review and future development. Compatibility with current WordPress and PHP versions has not been verified.

The original behavior includes publishing user email addresses. Review the code and the intended audience before using it on a live website.

## Original installation workflow

1. Download `ios-plugin.php.zip` from this repository.
2. In WordPress, open **Plugins → Add New → Upload Plugin**.
3. Upload and activate the ZIP file.
4. Add `[list_users]` to a Shortcode block in a post or page.
